# AYA Repository (Kodi)

Kodi repository for **AYA Translate**, a Kodi add-on that translates the subtitles you
download in Kodi into your language and loads them into the playing movie.
Works on Kodi 17 to 22.

This repository only holds the installable files. Install in Kodi:

1. Settings > System > Add-ons > turn on *Unknown sources*.
2. Settings > File manager > Add source > `https://randomfilip.github.io/aya-kodi-repo/` > name it `aya`.
3. Add-ons > Install from zip file > `aya` > `repository.aya-1.0.0.zip`.
4. Add-ons > Install from repository > AYA Repository > Program add-ons > AYA Translate.

Kodi then installs new versions automatically.
