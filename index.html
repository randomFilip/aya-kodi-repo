AYA Repository

Kodi repository for AYA Translate, which translates the subtitles you download in Kodi into your language and loads them into the playing movie. Works on Kodi 17 to 22.

Install in Kodi

  1. Settings → System → Add-ons → turn on Unknown sources.
  2. Settings → File manager → Add source → enter https://randomfilip.github.io/aya-kodi-repo/ and name it aya.
  3. Add-ons → Install from zip file → aya → repository.aya-1.0.0.zip.
  4. Add-ons → Install from repository → AYA Repository → Program add-ons → AYA Translate.

Files:

  • repository.aya-1.0.0.zip

Once the AYA Repository is installed, Kodi installs new AYA Translate versions by itself (Settings → System → Add-ons → Updates: Install updates automatically).
